PetGPT 更新检查方案

方案 B · 应用内检测 + 引导下载 · 2026-09-17

范围：启动后静默比对 GitHub 最新 Release，发现新版本就提示用户去下载 DMG。 不做下载、不解压、不替换 .app、不引入 tauri-plugin-updater、不需要签名密钥。 整体约 400–600 行新代码，风险面接近零。

01功能清单

F0

版本号单点化（前置阻塞项）

位置 scripts/create-dmg.sh:18 · scripts/create-dmg-intel.sh:18

现在版本号硬编码在 4 处，且 Intel 脚本还停在 0.4.4，实际已是 0.4.8。 让两个 DMG 脚本从 tauri.conf.json 读取 version，删掉硬编码。

整个方案靠版本号比较驱动，源头不一致会直接把错误版本号告诉用户 —— 必须先修这个。

F1

Rust 侧 check_for_update 命令

新建 src-tauri/src/updater.rs，注册进 lib.rs:3550 的 invoke_handler

请求 api.github.com/repos/JulesLiu390/PetGPT/releases/latest，可直接套用 qq_connector.rs:342 的 latest_release() 写法 —— 但要带自己的 User-Agent（GitHub 强制要求）并加 .timeout()。

当前版本从 app.package_info().version 取，编译期即来自 Cargo.toml，不用前端传。

返回 currentVersion / latestVersion / hasUpdate / releaseUrl / notes / pubDate / assetUrl / assetSize。

F2

架构感知的资产挑选

同 updater.rs，参照 qq_connector.rs:2540 的 OS/ARCH 匹配写法

std::env::consts::ARCH 为 aarch64 → 挑 *_aarch64.dmg，x86_64 → *_x64.dmg。

非 macOS 或找不到匹配资产时 assetUrl 留空，前端退化为「打开 Release 页」，不要把 Linux 用户指向 DMG。

F3

semver 比较（纯函数，带测试）

同 updater.rs + #[cfg(test)]

要处理 v 前缀、三段式、以及预发布标签 —— 0.5.0-beta 不能盖过 0.5.0。

手写十几行即可，不必为此给 Cargo.toml 增加 semver 依赖。

F4

节流与缓存

复用已有 get_setting / set_setting + src/utils/useSettings.js

新增 settings 键：updateCheckEnabled（默认 true）、lastUpdateCheckAt、lastKnownVersion、skippedVersion。

GitHub 匿名 API 限流 60 次/小时/IP，所以：检查间隔 ≥ 24h，启动后延迟约 60s 再查（不抢启动资源），网络失败一律静默，不打扰用户。

F5

Preferences 面板设置项

src/pages/ManagementPage.jsx:3171 PreferencesPanel

四项：当前版本显示、自动检查开关、「立即检查」按钮及结果状态、上次检查时间。

F6

新版本提示 UI

src/components/Chat/ChatboxBody.jsx 顶部 banner + Management 侧栏角标

不要放 character 窗口 —— 那是透明置顶的宠物形态，任何弹层都会破坏它。放 chat 窗口顶部一条可关闭的轻量 banner，Management 的 Preferences 入口加个小红点。

按钮：下载（shell:allow-open 权限已有）· 稍后 · 跳过此版本（写入 skippedVersion）。

F7

安装引导（本项目特有，不能省）

同 F6 提示组件；文案对齐 scripts/dmg-readme.rtf

应用未签名未公证，用户装完必须执行 sudo xattr -cr /Applications/PetGPT.app。 提示里要内嵌这条命令并提供一键复制（clipboard-manager:allow-write-text 权限已有）。

否则用户下完新版打不开，会以为更新把应用搞坏了。

F8

i18n 接线

src/i18n/messages.js · src/i18n/translator.js

固定文案成对加进 UI_MESSAGES（英文在前，它是源语言）。

带变量的句子（如「发现新版本 0.5.0」）必须走 translator.js 的 dynamicRules 正则规则 —— 这个项目是 DOM 层运行时替换，字面匹配对动态串无效。

F9

前端 wrapper 与测试

src/utils/tauri.js · src/utils/__tests__/

tauri.js 加 checkForUpdate() 包装。测试覆盖三个纯函数：semver 比较与资产挑选（cargo test）、节流判断与跳过逻辑（node --test）。

02明确不做的事

  • 不下载 DMG、不 hdiutil attach、不替换正在运行的 .app
  • 不引入 tauri-plugin-updater、不生成 minisign 密钥、不改 bundle.targets
  • 不做静默更新、不做强制更新

这三条正是方案 B 把风险压到零的原因：应用未签名未公证的前提下，自动替换 bundle 会撞上 Gatekeeper 和 macOS 13+ 的 App Management 保护。

03权限清单

src-tauri/capabilities/default.json 无需新增任何权限 —— shell:allow-open、clipboard-manager:allow-write-text、core:app:default 均已在列。
